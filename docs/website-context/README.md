# Bereichsweise Website-Pflege

Vor jeder Änderung den Skill „Fabians Website ändern“ lesen und befolgen. Vorschau, ausdrückliche Freigabe, Tests und Live-Prüfung bleiben erforderlich.

1. Passende Bereichsnotiz lesen: ETF.md oder Pressespiegel.md. Anschließend aktuelle Quellen, Git-Stand, offene PRs und Produktionsstand prüfen.
2. Gesprächsverlauf berücksichtigen. Bei Bezug auf frühere, hier nicht dokumentierte Entscheidungen Personal Context gezielt abfragen; Lücken kenntlich machen, keine vollständige Erinnerung behaupten.
3. Nach abgeschlossenen Änderungen die Bereichsnotiz um bestätigte Entscheidungen, betroffene Dateien, PR/Commit, Prüfungen und Rücknahmeziel ergänzen. Keine persönlichen Finanzdaten oder vollständigen Gespräche ins öffentliche Repository kopieren.
4. Der jeweilige Button muss stets denselben privaten Chat öffnen. Keine Skill-Startlinks oder öffentlichen Share-Links als Ersatz verwenden. Ein Chat-Link kann das automatische Neuladen eines Skills nicht erzwingen; die Anweisung zum Lesen des Skills gilt bei jeder Website-Aufgabe.

## Noch erforderlich
Die zwei Themen-Chats einmal vom Nutzer anlegen lassen, jeweils den Skill auswählen und den normalen Chat-Link aus der Adresszeile übermitteln lassen. Erst danach `Privat/bereich-chats.js` mit echten Adressen befüllen und funktionierende Links zur Freigabe vorlegen.
